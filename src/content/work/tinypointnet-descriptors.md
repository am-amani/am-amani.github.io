This work explored a smaller PointNet-inspired model for extracting local descriptors from point-cloud data.

The goal was to keep the architecture efficient while still producing useful features across different datasets and benchmark tasks.

Key focus points:

- Efficient neural design for 3D data
- Local descriptor learning from point clouds
- Evaluation across diverse benchmark scenarios
