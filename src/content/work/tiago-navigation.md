This project implemented goal-driven mobile robot navigation from a user-defined start point to a target destination.

An Action Client and Server structure was added to detect, report, and react to movable obstacles from laser-sensor data during navigation.

Key focus points:

- ROS navigation stack integration
- Event-driven communication with action interfaces
- Obstacle awareness and reporting during navigation
